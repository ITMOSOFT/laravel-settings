## [1.1.0] - 2026-10-14

### Added
- Add `all()` to retrieve all settings as an associative array ordered by key.
- Add `setMany()` to create or update multiple settings in a bulk database operation.
- Add tests for empty arrays, zero values, timestamp preservation, invalid UTF-8, and bulk operations.
- Document the new API methods and their behavior.

### Quality
- Expand automated test coverage from 7 to 19 tests.
- Document facade methods for improved IDE autocomplete.
